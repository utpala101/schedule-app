Features

四个模块，一个工具

日程 · 待办 · 记录 · 统计

📅

日历视图

月 / 周 / 日三种视图快速切换，智能时间管理。

  • 折叠 0:00-6:00 / 22:00-24:00，只展示工作时段
  • 有日程时折叠条高亮提示
  • 主题色当前时间指示线
  • 编辑时开始↔持续↔结束智能联动
  • 月视图外月日期自动淡化，层次分明
  • 按住时间槽拖拽直接划定起止创建日程
  • 事件悬停快捷完成/删除按钮
  • 月视图拖拽事件到任意日期
  • 周/日视图拖拽事件边缘修改起止时间
🎯

四象限待办

艾森豪威尔矩阵管理任务优先级。默认显示当天待办，可查看任意日期。

  • 四种颜色区分优先级
  • 子任务逐项勾选，主任务自动同步
  • 主任务勾选/取消 → 全部子任务同步
  • 拖拽到其他象限改变优先级
  • 未分类日程单独显示
✍️

工作记录

结构化表单 + 自由备注，记录每天的工作内容。支持关键字搜索和历史回溯。

  • 日期、项目、标签、耗时结构化录入
  • 自由文本备注区域
  • 按日期分组展示
📊

统计看板

五种图表可视化你的工作效率——折线图、饼图、柱状图、热力图。

  • 每日完成待办趋势
  • 各项目耗时分布
  • 四象限任务分布
  • 日历贡献热力图
🔗

数据统一，双向同步

日程事件和待办事项不再割裂。一个事项可以同时拥有时间（上日历）和象限（进四象限）。在任何一端创建或修改，另一端自动同步。

  • 统一数据模型，没有数据不一致
  • 标注四象限的日程自动出现在待办中
  • 设置时间的待办自动显示在日历上

💾

本地存储，数据归你

纯前端 SPA，数据存在你指定的 JSON 文件中。没有服务器，没有云端，没有隐私泄露。

  • 支持 File System Access API（Chrome）
  • 自动降级到 IndexedDB
  • JSON 导入/导出方便迁移
  • 按时间段导出 + 打印 PDF
🎨

Warm Studio 设计

暖色调手账风格——陶土红、奶油白、稻纸纹理。不是冷冰冰的蓝色生产力工具。

  • 亮色/暗色主题切换
  • 纸纹噪点叠加层
  • 精致阴影和微动效
⚡

纯前端，零依赖

一个 HTML 文件 + 几个 JS/CSS 文件，双击就能运行。不需要 Node.js、不需要数据库、不需要部署。

  • Tailwind CDN 快速样式
  • Chart.js 轻量图表
  • IndexedDB 浏览器原生存储
